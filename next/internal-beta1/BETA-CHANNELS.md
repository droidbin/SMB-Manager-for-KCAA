# 베타 채널 — 내부 시험 빌드 2

앱 표기는 `2.0.0-beta.1`, 설치 제품 버전은 `2.0.103`입니다. 기존 내부 베타 1(2.0.101)을 업그레이드하며 등록 정보와 HTTPS 설정을 유지합니다.

| 채널 | 서버가 허용하는 대상 |
| --- | --- |
| 오픈베타 (`open-beta`) | 관리자가 등록 승인한 PC |
| 클로즈베타 (`closed-beta`) | 등록 승인 + 서버 배정 부서가 정확히 `운영부`, 또는 관리자가 별도로 관리자 자격을 부여한 PC |

오픈베타도 현재 사내 시험 서버 내 채널이며 인터넷 공개를 의미하지 않습니다. 이번 빌드는 GitHub나 기존 정식/베타 피드에 게시하지 않습니다.

## 관리자 설정

1. 채널 기능이 들어간 설치본으로 관리자 PC와 시험 클라이언트를 업그레이드합니다.
2. 요청한 PC의 실제 사용자를 확인하고 등록을 승인합니다. PC 이름이나 Windows 사용자 이름만으로 자격을 판단하지 않습니다.
3. 운영부는 **PC 부서·권한 관리**에서 `운영부`와 실제 운영부 Drive 계정을 배정합니다. 공유를 아직 연결하지 않을 경우 선택 공유 없이 배정할 수 있습니다. SMB 서버의 실제 ACL도 별도로 확인합니다.
4. 관리자 PC는 **베타 접근 관리**에서 관리자 자격을 부여합니다. Windows 관리자 계정이라고 자동 승인하지 않습니다. 이 자격은 Drive 공유 권한을 추가하지 않습니다.
5. 클라이언트의 **베타 채널 → 권한 새로고침**에서 허용 채널을 선택하고 배포를 확인합니다.

클라이언트가 전송하는 부서/관리자 필드, PC 이름, MAC 주소, 비밀번호로 클로즈베타 자격을 자동 부여하지 않습니다. 기존 장치는 관리자 자격 없음/오픈베타 기본값으로 이관합니다. 운영부 부서 변경이나 관리자 자격 회수 후 신규 조회·다운로드는 즉시 거절합니다. 이미 시작한 다운로드와 이미 받은 설치 파일을 원격 삭제하지는 않습니다.

## 배포 파일 등록 (서버 관리자 전용)

QA가 통과한 후보를 아래 명령으로 현재 관리자의 서버 데이터 폴더에 등록합니다. 직원에게 이 명령이나 서버 데이터 폴더를 전달하지 않습니다. 실행 중인 관리자 프로그램과 같은 Windows 사용자로 실행해야 합니다.

```powershell
.\Publish-BetaRelease.ps1 -Channel closed-beta -CandidateRoot .\.local\beta1-channels-verified
```

기본 위치는 `%LOCALAPPDATA%\SMB Manager Internal Beta 1\server\beta-releases\closed-beta`입니다. 별도 `--profiles-file` 서버를 쓰면 해당 프로필 파일의 부모 폴더를 `-ServerDataRoot`로 지정합니다. 파일과 `release.json`은 HTTPS의 정적 파일 경로로 노출하지 않습니다. 인증된 장치 API만 허용합니다. 오픈베타에 등록하려면 채널을 명시적으로 바꿔 별도 등록해야 합니다.

클라이언트는 다운로드를 다시 인증하며 SHA256·크기를 검증한 후 저장합니다. 설치는 사용자가 직접 실행합니다. 채널 선택은 자동 실행·강제 업데이트나 보안 제품 예외 설정을 만들지 않습니다. 설치본과 ZIP을 직접 전달한 경우 복사 자체를 제한할 수 없으므로 클로즈베타 초기 설치 ZIP은 운영부·관리자에게만 전달하세요. 이 기능의 접근 제한 대상은 서버의 채널 조회·배포 파일 다운로드입니다.

## 시험 범위

인증 없는 접근, 미승인 PC, 타 부서, 관리자 이름 사칭, JSON 권한 위조, 장치 키로 관리자 API 호출, 부서 변경, 관리자 자격 회수, 서버 재시작, 구 상태 이관, 파일 변조·경로 탈출, 클라이언트 해시 검증을 회귀 시험합니다. 채널 변경/회수는 기존 업무용 SMB 연결을 일괄 해제하지 않습니다.
