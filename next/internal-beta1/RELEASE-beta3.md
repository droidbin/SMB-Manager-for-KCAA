# SMB Manager 2.0.0-beta.3 · 빌드 11

회사 내부 시험을 위한 베타입니다. 정식 최신 버전은 1.7.11로 유지합니다.

## 이번 변경
- 관리자 앱에 GitHub 업데이트 확인 버튼을 추가했습니다. 정식·베타 선택 및 관리자 설치 ZIP 다운로드를 지원합니다.
- 관리자용 파일만 선택하고 다운로드 크기·SHA-256을 검증합니다. 오류·취소 시 임시 파일을 정리하며 기존 파일은 덮어쓰지 않습니다.
- 관리자 ZIP 암호는 앱에 내장하지 않습니다. 별도로 받은 암호로 압축 해제하고 MSI를 직접 실행합니다.
- 직원 업데이트 화면의 현재 버전 표기를 실제 설치 버전과 일치시켰습니다.

## 유지되는 기능
회사 알림 팝업, 1.7 스타일의 검은 메시지 영역, 관리자 일괄 재연결·연결 해제, 한글 Drive 암호 입력, 연결 누락 복구 및 서버 인증 실패 시 반복 인증 중지를 포함합니다.

## 파일 및 설치
- Client ZIP: 직원용 MSI·안내·체크섬.
- Admin ZIP: 관리자용 MSI·안내·체크섬. AES-256 암호 ZIP. 기존 관리자 배포 암호를 별도로 사용하며 GitHub에는 올리지 않습니다.
- SHA256SUMS.txt: 다운로드 ZIP 확인용.

이 기능이 없는 기존 관리자 앱에서는 새 관리자 설치본을 한 번 직접 설치하세요. 이후 앱의 업데이트 확인으로 다음 관리자 배포 ZIP을 받을 수 있습니다.

설치 전 공유폴더 파일을 저장하고 닫으세요. 현재 Windows 사용자의 기존 SMB 연결 전체와 저장 매핑을 정리하고 확인된 1.7 설치 파일을 제거합니다. 열린 파일은 강제로 끊지 않으며 정리 실패 시 설치 완료를 보류합니다. 기존 설정·저장 암호 파일은 보존하지만 2.0 등록·부서 승인은 별도입니다.

관리자 업데이트 시 직원들의 공유폴더 작업을 저장한 뒤 관리 서버를 완전히 종료하고 MSI 설치 후 다시 실행하세요. 서버 중단 동안 관리 연결이 회수될 수 있으므로 업무 종료 후 진행하세요. 회사 사내망 및 실행 중인 관리 서버가 필요합니다. 클로즈베타는 기존 운영부·관리자 권한을 유지합니다.

## QA
격리 통합·연결 회귀 검사와 GitHub 실 다운로드·해시 검사, Windows 시험 PC에서 관리자·직원 MSI 설치·구버전 제거·SMB 초기화 및 설치 후 화면·파일 해시 검증을 수행합니다. 배포 전 최종 결과는 릴리즈 검증보고서를 확인하세요.

코드 서명 인증서가 없는 베타입니다. AhnLab·알약 및 은행 보안 프로그램 전체 조합의 호환성을 보장하지 않습니다. 이전 베타 릴리즈는 새 릴리즈 확인 후 정리하며 정식 1.7.11은 유지합니다.
