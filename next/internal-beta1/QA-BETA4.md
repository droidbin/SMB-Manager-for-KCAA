## 실제 확인한 동작

- 직원 설치 시 확인된 1.7 실행 파일을 제거하고 현재 Windows 사용자의 모든 SMB 매핑을 해제했습니다. 기존 설정·암호 파일 및 관련 없는 파일은 보존했습니다.
- 열린 SMB 파일을 강제로 끊지 않았고, 설치 마무리 실패가 기록됐습니다. 파일을 닫고 설치를 다시 실행했을 때 완료됐습니다.
- 관리자 설치 중 직원 앱과 SMB 파일을 열어 두었습니다. 설치가 성공했고 연결·열린 파일·직원 설정이 보존됐습니다. 관리자 설치는 직원 연결 초기화를 실행하지 않습니다.
- 기존 관리자 패키지에 포함된 중복 직원 실행 파일이 제거됐고 독립 직원 설치본은 보존됐습니다.
- 지속 재연결을 꺼도 앱을 다시 실행하면 배정 Drive가 실제로 복구됐습니다. 관리자 연결 중지는 새 연결을 만들지 않았습니다.
- 인증 실패, 보안 격리, 정책 만료, 드라이브 문자 충돌 및 다른 부서 계정으로의 잘못된 배정을 거절하는 기존 회귀 검사를 통과했습니다.
- 설치 화면·직원 화면·큰 알림 팝업·관리자 업데이트 화면을 검사했습니다. 시험 PC 기존 사용자의 X:·Y: 드라이브는 화면 검사 전후 유지됐습니다.

## 수정 과정과 남은 제한

이전 후보의 자동 앱 종료 경합 시험이 실패하여 해당 후보는 배포에서 제외했습니다. 최종본은 관리자·직원 설치를 분리하고, 직원 앱 잠금이 남아 있으면 연결 정리를 진행하지 않고 완전 종료 후 재설치를 안내합니다.

초기 SMB 시험 두 번은 시험 파일 문구 불일치와 시험 PC 관리 서버의 이전 버전 때문에 중단됐습니다. 시험 데이터와 설치 버전을 맞춘 뒤 전체 실제 SMB 29개 항목을 다시 통과했습니다.

글꼴·창 크기 확대 시험은 실제 Windows DPI 설정 변경 시험을 대신하지 않습니다. 화면이 작은 경우 스크롤을 사용합니다. Windows가 사용 중으로 유지하는 삭제된 임시 시험 프로필은 강제 해제하지 않았습니다.

코드 서명 인증서가 없습니다. Defender 위협 미검출이 모든 보안 제품의 허용을 보장하지 않습니다. AhnLab Safe Transaction, 알약, TouchEn, nProtect, INISAFE, VeraPort 및 은행·카드·홈택스 조합의 전체 실사용 호환성은 아직 검증되지 않았습니다.

베타만 게시하며 정식 최신 V1.7.11은 유지합니다. 관리자 ZIP은 AES-256 암호화하고 실제 암호·서버 데이터·등록 키·인증서 개인키를 공개 파일에 포함하지 않습니다. 회사 업데이트는 클로즈베타 접근 규칙을 유지하며 오픈베타·정식 채널은 변경하지 않습니다.
