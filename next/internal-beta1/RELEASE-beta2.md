# SMB Manager 2.0.0-beta.2 · 빌드 10

회사 내부 시험을 위한 베타입니다. 정식 1.7.11은 계속 유지됩니다.

## 변경 사항
- 직원에게 보낸 회사 알림을 별도 팝업창으로 표시합니다. 새 알림은 같은 창에 추가하고, 확인하면 읽음 처리합니다.
- 회사 알림의 메시지 영역을 1.7.11과 같은 짙은 배경·밝은 글자로 변경했습니다.
- 관리자 앱에 접속 PC 일괄 재연결·연결 해제를 추가했습니다. 연결 해제 후 자동 재연결은 보류하고 부서·폴더 배정은 유지합니다.
- 관리자 Drive 암호 입력에 한글 입력·표시 옵션을 추가했습니다.
- 누락된 연결 작업 복구와 서버별 인증 실패 시 반복 인증 중지를 포함합니다.

## 파일
- Client ZIP: 직원용 설치 MSI와 설치 안내.
- Admin ZIP: 관리자용 설치 MSI와 설치 안내. AES-256 암호 ZIP이며 암호는 관리자에게 별도로 전달합니다. AES ZIP을 지원하는 압축 프로그램을 이용하세요.
- SHA256SUMS.txt: 다운로드 파일 무결성 확인용.

## 설치 전
열려 있는 공유폴더의 파일을 저장하고 닫으세요. 설치한 Windows 사용자의 기존 SMB 연결 전체와 저장 매핑을 정리하고 확인된 1.7 설치 파일을 제거합니다. 열린 파일은 강제로 끊지 않으며 정리 실패 시 설치 완료를 보류합니다. 기존 설정·저장 암호 파일은 보존하지만 2.0 등록·부서 승인은 별도입니다.

회사 사내망에서 관리자 서버가 실행 중이어야 합니다. 관리자용 압축파일에는 서버 데이터, 실제 Drive 암호, 인증서 개인키, 등록 코드가 포함되지 않습니다. 클로즈베타·오픈베타 권한 구분은 유지합니다.

## 검증
- 통합 QA 148개, 회귀 QA 93개 통과.
- 별도 Windows 시험 PC에서 관리자 MSI 20개, 직원 MSI 25개 설치·초기화 검사 통과.
- 로컬 UI 기본·최소 크기 및 글자 확대 검사 통과. 새 팝업 기본·최소 크기 검사 통과.
- 실제 설치된 직원 앱·팝업 실행 검사 4개 통과. 시험 전후 기존 사용자 드라이브 목록 동일.
- 관리자 설치 파일 659개, 직원 설치 파일 490개 해시 일치.
- Windows Defender 설치 파일 검사: 위협 발견 없음.

코드 서명 인증서가 없는 베타입니다. AhnLab·알약 및 은행 보안 프로그램 전체 조합의 호환성 시험을 완료한 것은 아닙니다. 문제가 있으면 광범위 배포를 중지하고 시험 PC에서 재현해 주세요.
