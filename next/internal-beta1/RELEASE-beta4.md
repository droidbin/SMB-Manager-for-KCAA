# SMB Manager 2.0.0-beta.4 · 빌드 13

회사 내부 시험용 베타입니다. 정식 최신 버전은 1.7.11을 유지합니다.

## 변경 사항
- 회사 알림 영역과 글자를 키우고, 크게 보기 창과 긴 메시지 스크롤을 추가했습니다. 새 회사 알림은 팝업으로 표시합니다.
- 앱을 켜면 배정된 Drive를 자동으로 복구합니다. 관리자 연결 중지, 보안 격리, 인증 실패로 중단한 연결은 임의로 다시 시도하지 않습니다.
- 연결 상태와 다음 행동을 쉬운 문장으로 표시하고, 연결된 폴더를 자동 선택합니다.
- 관리자 MSI에서 직원 앱을 제외했습니다. 관리자와 직원 설치본을 함께 사용해도 직원 앱은 한 번만 설치됩니다. 기존 통합 관리자 패키지의 중복 직원 앱은 관리자 업데이트 시 제거됩니다.
- 관리자 설치가 직원 앱의 실행 잠금 때문에 실패하거나 직원의 SMB 연결을 초기화하는 문제를 수정했습니다.

## 설치 파일
- Client ZIP: 직원 전용 MSI, 이 안내문, MSI 체크섬.
- Admin ZIP: 관리자·관리 서버 전용 MSI, 이 안내문, MSI 체크섬. AES-256 암호 ZIP이며 기존 관리자 배포 암호를 별도로 사용합니다.
- SHA256SUMS.txt: ZIP 및 QA 보고서 확인용.
- QA-Report.md: 실제 수행한 검증 결과와 한계.

## 설치 순서
직원 PC에는 Client만 설치하세요. 관리자 PC에서도 공유폴더를 연결하려면 Client를 별도로 설치합니다. 기존 통합 관리자 패키지를 사용하던 PC는 Client를 먼저 설치하고 Admin을 업데이트하세요.

직원 설치 전에는 공유폴더 작업을 저장하고 파일·탐색기 창을 닫으세요. 알림 영역의 직원 앱에서 앱 완전히 종료를 선택한 뒤 설치합니다. 직원 설치 마지막 단계에서 해당 Windows 사용자의 기존 SMB 연결 전체·저장 매핑과 확인된 1.7 실행 파일을 정리합니다. 열린 파일은 강제로 끊지 않으며, 앱 실행 중이거나 정리가 실패하면 설치 마무리를 보류하므로 안내에 따라 재시도하세요. 저장 설정·암호·등록 정보는 보존합니다.

관리자 설치는 SMB 연결 초기화를 수행하지 않습니다. 관리 서버를 완전히 종료하고 Admin MSI 설치 후 다시 실행하세요. 서버 중단 시 직원 연결이 회수될 수 있으므로 업무 종료 후 진행하세요. 관리자와 직원 앱은 각각 기존 설치본을 업그레이드합니다.

사내망과 실행 중인 관리 서버가 필요합니다. 클로즈베타 접근 권한은 운영부·서버에서 지정한 베타 관리자만 유지하며 오픈베타·정식 채널에는 배포하지 않습니다. GitHub의 베타 첨부 파일은 공개 다운로드입니다.

코드 서명이 없는 베타입니다. Defender 검사 결과는 QA 보고서에 기록하며 AhnLab·알약·은행 보안 프로그램 전체 조합의 호환성은 아직 검증되지 않았습니다.
