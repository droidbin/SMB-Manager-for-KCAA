# 1.x 소스 이력

버전별 소스·문서·설정·과거 QA 기록을 보존합니다. 최종 설치파일은 GitHub Releases에서 받습니다. `integrity.sha256` 등 기존 기록은 당시 배포본의 기록이며 새 로컬 빌드의 체크섬이 아닙니다.

공유 폰트는 저장소의 `assets/fonts/noto-sans-cjk-kr`에 있습니다. 각 `source/build.ps1`의 결과는 `.local/legacy-builds`에 생성됩니다.

**기존 이력의 불일치:** `SMB Manager V1.7.7` 폴더의 원래 `version.ini`와 `Program.cs`는 V1.7.8을 가리킵니다. 해당 코드를 임의로 바꾸거나 V1.7.7 재현본으로 표시하지 않습니다. 이 폴더를 빌드하면 V1.7.8로 출력됩니다. 게시 도구는 요청 버전·버전 파일·앱 소스 버전이 다르면 거절합니다. V1.7.7의 기존 릴리스와 태그는 보존합니다.

실제 공개 2.x 소스가 없는 빌드 25의 재현 한계는 [배포와 소스 이력](../../docs/DISTRIBUTION.md)에 설명합니다.
