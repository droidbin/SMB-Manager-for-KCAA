# SMB Manager

Windows SMB 공유폴더를 부서별 드라이브로 연결하고, 연결 상태 점검과 자동 복구를 지원하는 **사내 업무용 프로그램**입니다. 개인·외부 기관·기업 대상 업데이트는 제공하지 않습니다.

## 다운로드

|---|---|---|
| **정식** | **2.0.17** (파일 버전 2.0.164.0) | [V2.0.17 릴리스](https://github.com/droidbin/SMB-Manager-for-KCAA/releases/tag/V2.0.17) · [Latest](https://github.com/droidbin/SMB-Manager-for-KCAA/releases/latest) |
| 관리자 전용 | **2.1.3** (파일 버전 2.1.164.0) | [V2.1.3 릴리스](https://github.com/droidbin/SMB-Manager-for-KCAA/releases/tag/V2.1.3) (암호 ZIP, 암호는 담당자에게 따로 받습니다) |
| 1.7 사용자 전환용 | V1.7.14 (안에 든 설치본은 2.0.10) | [V1.7.14 릴리스](https://github.com/droidbin/SMB-Manager-for-KCAA/releases/tag/V1.7.14) |

현재 정식보다 낮은 버전은 GitHub에서 받을 수 없습니다. 어떤 버전을 쓰고 있든 업데이트하면 바로 최신 정식으로 올라갑니다.

| 지금 쓰는 버전 | 업데이트 방법 |
|---|---|
| 2.0 정식 | 앱의 **업데이트 → 다시 확인**. 회사 관리 서버가 최신 정식(2.0.17)을 안내합니다 |
| 2.0 베타 | 같은 방법으로 현재 정식과 같은 **2.0.17**(파일 버전 2.0.164.0)을 안내합니다(별도 베타 버전 없음) |
| 1.7.7 · 1.7.8 | 앱의 업데이트 확인. 정식 릴리스의 직접 업데이트 zip(`SMB-Manager-1.7-Direct-Update-V2.0.17.zip`)으로 2.0.17을 설치합니다 |
| 1.7.9 ~ 1.7.12 | 앱의 업데이트 확인. 전환 릴리스 V1.7.14로 2.0.10을 설치한 뒤, 2.0 앱의 **업데이트 → 다시 확인**으로 2.0.17에 올라갑니다 |

1.7에서 업데이트하면 회사 서명된 `Setup.exe`가 함께 든 설치 파일의 해시와 서명을 확인한 뒤 설치합니다. 설치가 끝나면 2.0 앱이 1.7 실행 파일과 바로가기를 정리합니다. 설치를 취소하거나 실패하면 1.7 앱을 계속 사용할 수 있습니다.

설치 전에 업무 파일을 저장하고, 공유폴더 문서와 탐색기 창을 닫아 주세요. 관리자/서버 프로그램은 직원용 설치본에 포함되지 않습니다.

## 2.0.17 주요 내용

전체 임직원 대상 정식 버전입니다. 2.0.11 이후 베타에서 다듬은 변경을 모두 담았습니다.

- **공지 팝업:** 앱이 최소화되어 있거나 트레이에 있어도 회사 공지를 팝업으로 보여줍니다. 메인 창 아래의 이전 공지 목록은 없어졌습니다.
- **업무지원포털 앱:** 기존 바탕화면·시작 메뉴 바로가기를 정리합니다. 앱이 이미 설치돼 있으면 더 설치하지 않고, 없으면 Chrome(없으면 Edge) 한 곳에만 정책으로 설치합니다(브라우저에 조직 관리 표시가 나타날 수 있음).
- **컴퓨터 이름 변경 안내:** 등록된 성명과 PC 이름이 다르면 회사 정책에 따라 변경이 필요하다는 창을 앱 시작 시와 하루 한 번 보여줍니다. 확인과 Windows 권한 창에서 승인한 경우에만 바뀌며 다음 재시작 후 적용됩니다.
- **계정 잠김 예방:** 이전 영구 매핑과 저장된 계정을 정리하고, 인증에 실패하면 자동 재연결을 잠시 멈춥니다.
- **강제 업데이트:** 관리자가 지시한 강제 업데이트는 10분 안내가 끝나면 **열린 파일을 포함해 공유폴더 연결을 강제로 끊고** 설치합니다. 저장하지 않은 작업은 사라질 수 있으니 안내가 보이면 먼저 저장하세요.
- **설치 전 확인:** 업데이트할 때 이 Windows 사용자의 기존 공유폴더 연결과 저장 매핑을 해제합니다. 공유폴더의 작업 파일과 탐색기 창을 먼저 닫으세요. 앱이 배정된 폴더를 다시 연결합니다.

## 2.0.11 주요 내용

서버 비밀번호를 바꾼 뒤 공유폴더 연결이 끊기고 서버 계정이 잠기던 문제를 고쳤습니다.

- **계정 잠김 방지:** 인증에 실패하면 같은 서버에 대한 재시도를 잠시 보류합니다(암호 오류 2분, 계정 잠김 15분). "다시 연결"을 반복해 눌러도 인증 시도가 서버로 나가지 않아 잠금이 길어지지 않습니다. 새 암호가 배정되거나 관리자가 복구를 지시하면 바로 다시 시도합니다.
- **서버 암호 변경 후 연결 복구:** 서버 암호가 바뀌면 같은 서버의 앱 연결을 함께 정리하고 새 암호로 다시 맺습니다. 이전에는 한 드라이브만 끊겨도 나머지 드라이브가 옛 암호 연결을 잡고 있어 오류 1219로 복구되지 않았습니다. 열린 파일은 강제로 닫지 않습니다.
- 계정 잠김 상태를 화면에서 "계정 잠김"으로 구분해 보여줍니다.

## 관리자 2.1.3 주요 내용 (관리자 전용)

관리자 앱만 바뀐 릴리스입니다. 직원용 앱은 별도의 2.0.11이며 Latest 표시는 직원용에 있습니다. 2.1.2의 모든 변경을 포함합니다.

- **관리 서버 경량화:** 장치 목록·명령 기록을 변경분만 조회하는 증분 API를 추가해 반복 조회 크기를 줄였습니다(명령 응답 2.76MB → 약 150KB). 오래된 완료 명령은 7일 또는 최근 500건만 남기고, 진행 중 명령은 보존합니다. 하트비트·명령 대기열처럼 자주 바뀌는 상태만 0.5초 묶음으로 저장하고, 승인·철회·배정 같은 관리자 조작은 즉시 저장합니다.
- **관리 화면 사용량 감소:** 화면이 보일 때 5초, 숨겨졌을 때 30~60초 간격으로 갱신하고 오류가 나면 간격을 늘립니다. 렌더러가 종료되면 자동으로 다시 열고, 서버가 재시작되면 다시 연결합니다.
- **구형 WinForms 관리 화면(AdminDesktop) 제외:** 최신 관리자 설치본에는 웹 기반 관리 화면만 들어갑니다.
- **확인한 범위:** 관리자 PC(Windows 11)에 2.1.2 위로 실제 설치해 운영 데이터 보존과 파일 667개 일치를 확인했고, 별도 Windows 10 시험 PC에서 30분 메모리 추이와 렌더러·서버 재시작 복구를 확인했습니다. 목표로 잡은 패키지 크기 25%·서버 CPU 70%·셸 메모리 30% 절감은 달성하지 못했습니다(런처가 쓰는 .NET 데스크톱 런타임을 포함해 설치 파일은 오히려 약 32MB 커졌습니다).
- 서버 계정 제어의 실제 Windows 서버 시험, Cloudflare 실제 접속·모바일 접속, 직원 PC 강제 업데이트 실설치는 이번에도 확인하지 못했습니다.

## 관리자 2.1.2 주요 내용 (관리자 전용)

관리자 앱만 바뀐 릴리스입니다. 직원용 앱은 별도의 2.0.11이며 Latest 표시는 직원용에 있습니다.

- **잠긴 계정 복구 보호:** 직원 PC가 서버 계정 잠김을 보고하면 "배정 폴더 복구"(단일·일괄)를 보내지 않고 이유를 알려줍니다. 서버에서 잠금을 이미 풀었다면 "해제 확인 후 복구"로 보낼 수 있습니다.
- **서버 계정 제어(선택 기능, 기본 꺼짐):** 폴더·부서 화면에서 SMB 서버(Windows)의 로컬 계정 잠금을 조회·해제하고, 서버 암호와 앱에 저장된 암호를 한 번에 바꿉니다. 서버가 먼저 변경에 성공해야 앱의 암호가 바뀌고, 서버 관리자 계정·암호는 관리자 PC에 암호화 저장하며 직원 PC에는 전달하지 않습니다. 데스크톱 관리 화면에서만 열립니다.
  - **실제 Windows 서버에서는 아직 시험하지 못했습니다.** 처음 쓸 때는 먼저 "잠금 상태 조회"로 연결을 확인하세요.
- 업무지원포털 바로가기를 관리 화면 상단에 추가했습니다.

## 관리자 2.1.1 주요 내용 (관리자 전용)

2.1.0의 모든 변경을 포함하며, 직원 요청을 푸시 알림으로 받는 기능이 추가됐습니다. 직원용 앱은 변경이 없고 Latest 표시는 직원용 2.0.10에 그대로 있습니다.

- **업무지원포털 푸시 알림(기본 꺼짐):** 직원이 PC 등록·정보 정정·오류 신고를 요청하거나 보호 차단이 보고되면 포털의 통합 관리자 기기(PWA·브라우저, Android 앱 1.11.0 이상)로 알림이 갑니다.
  - 알림에는 요청 종류와 건수만 담기고 직원 이름·PC 이름·경로는 들어가지 않습니다.
  - 설정은 관리자 PC 전용 화면에서만 바꿀 수 있고, 비밀키는 암호화 저장하며 서버 백업에는 포함하지 않습니다.
- 핵심 QA는 **18/18(100%)**이며, Cloudflare 실제 접속·모바일 접속과 직원 PC 강제 업데이트 실설치는 2.1.0부터 이어진 미확인 항목입니다.

## 관리자 2.1.0 주요 내용 (관리자 전용)

관리자 PC(Windows 11)에 설치하는 관리 프로그램입니다. 직원용 앱은 변경이 없고, GitHub의 Latest 표시는 직원용 2.0.10에 그대로 있습니다.

- **새 관리 화면:** 웹 기반(Electron) 화면으로 개편했습니다. 왼쪽 메뉴와 모바일 폭을 지원하며, 기존 화면은 복구용으로 함께 설치됩니다.
- **원격(모바일) 관리:** 외부에서 관리 기능만 사용할 수 있습니다. 기본은 꺼져 있습니다.
  - 계정·암호·인증 앱 코드를 모두 요구하고, 5회 실패하면 15분 잠깁니다. 삭제·배정 같은 중요한 작업은 인증 앱 코드를 다시 확인합니다.
  - 공유폴더 파일, 직원 등록, 설치 파일은 원격으로 열리지 않습니다. 백업 설정·복원, 자산 내보내기, 원격 설정은 관리자 PC에서만 할 수 있습니다.
- **Cloudflare 터널·Access 연동:** 외부 접속을 Cloudflare Access 로그인으로 보호하는 설정 화면을 추가했습니다.
- **설치 안정성:** 관리자 앱 업그레이드 중 서버 종료 지연으로 설치가 되돌려지던 문제를 보강했습니다.
- 핵심 QA는 **17/18(94.4%)**이며, Cloudflare 실제 접속과 모바일 접속은 실환경에서 처음 켤 때 별도로 확인해야 합니다.

## 2.0.10 주요 내용

- **실명 등록:** 등록 성명은 실명 한글 2~4글자만 받습니다(공백·직함·영문·숫자 불가).
  - 이미 등록된 성명이 규칙에 맞지 않으면 앱 실행 시 '실명 등록 필요' 창이 뜹니다.
  - 보낸 실명은 담당자 승인 후 반영됩니다. 그동안 공유폴더 연결은 그대로 유지됩니다.
- **1.7 사용자:** 업데이트 확인 한 번으로 2.0.10을 바로 설치합니다.
- **관리 서버 무중단·상태 점검:** 관리 서버가 비정상 종료되면 자동으로 다시 시작합니다.
  - '서버' 화면에서 다음 항목을 경고와 함께 보여줍니다.
    - 디스크 여유
    - 저장 오류
    - HTTPS 인증서 만료
    - 마지막 백업
    - 자동 재시작 기록
- **자동 백업·복원:** 서버 데이터를 매일 백업합니다(기본 14개 보관).
  - '지금 백업', 암호 걸린 '이동용 백업', '복원'을 지원합니다.
  - 복원 전 데이터는 지우지 않고 옆 폴더로 옮겨 둡니다.
- **관리 화면 개편:** 왼쪽 메뉴와 홈 화면으로 정리했습니다.
  - PC 목록에 앱 버전·마지막 접속을 표시합니다.
  - 변경 이력을 검색하고 CSV로 저장할 수 있습니다.
- **끊김 알림:** 배정 폴더가 1분 넘게 끊겨 있으면 알림을 띄웁니다. 누르면 연결 진단이 열립니다.

## 2.0.8 주요 내용

- **관리자 업데이트 적용:** 관리자가 관리 프로그램에서 PC를 골라 최신 버전 설치를 요청할 수 있습니다.
  - 직원 화면에 10분 안내가 뜨고, 시간이 되면 앱이 종료된 뒤 자동으로 설치되고 다시 실행됩니다.
  - 설치는 함께 설치되는 'SMB Manager 업데이트 서비스'가 맡습니다. 이 서비스는 회사 서명된 직원 앱 설치 파일만, 현재보다 높은 버전으로만 설치합니다.
- **부서 변경 후 연결 안 되던 문제 수정:** 같은 회사 서버에 이전 부서 계정 연결이 남아 있으면 Windows가 새 계정 연결을 거부했습니다(오류 1219). 이제 앱이 남은 연결과 저장된 자격 증명을 자동으로 정리합니다. 열린 파일 때문에 정리하지 못하면, 파일이 닫히는 대로 자동으로 연결합니다.
- **업데이트 채널 정리:** 정식·베타 두 가지만 운영합니다. 이전 버전 앱의 예전 채널 요청도 베타로 안내합니다.

전체 변경 이력은 [업데이트 내역](docs/CHANGELOG.md)을 확인하세요.

## 테스트와 배포 기준

- **베타:** 내부 Windows 10/11 VM과 부서원 대상 시험.
- **정식:** 핵심 QA 필수 세부 항목의 통과율이 90% 이상이어야 합니다. 또한 중대 결함이 없고, 설치본 서명·무결성과 복구 준비, GitHub 및 회사 서버를 통한 실제 업데이트 전달을 확인해야 전체 임직원 대상으로 전환합니다.
- 핵심 QA 항목:
