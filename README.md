# SMB Manager

Windows SMB 공유폴더를 부서별 Drive로 연결하고 연결 상태 점검·자동 복구를 지원하는 **사내 업무용 프로그램**입니다. 개인·외부 기관·기업 대상 업데이트는 제공하지 않습니다.

## 테스트와 배포

앞으로 알파·클로즈베타·오픈베타를 별도 단계로 운영하지 않습니다.

- **베타:** 내부 Windows 10/11 VM과 부서원 대상 테스트.
- **정식:** 핵심 QA 필수 세부 항목의 통과율이 90% 이상이고 중대 결함·설치본 무결성·업데이트 전달 확인을 완료하면 전체 임직원 대상으로 전환.
- 정식 전환 후에도 발견한 문제를 수정해 계속 업데이트합니다.

핵심 QA는 실제 설치·업데이트와 등록/설정 보존, 실제 서버 연결·권한·파일 작업, 변경 영향과 중대 문제, 서명·무결성·복구, GitHub 및 인증된 앱 전달입니다. 미실행·실패·차단은 통과로 세지 않습니다. 장시간 반복·전체 화면 조합·광범위 호환성 검사는 확장 검사 기록으로 보존합니다.

기존 릴리스의 알파/클로즈/오픈 명칭은 당시의 배포 이력입니다. 당시 QA 예외·미완료 기록과 태그·설치파일은 유지합니다. 명칭 정리는 기존 베타의 정식 승인을 뜻하지 않습니다. [배포 기준과 이력](docs/DISTRIBUTION.md)을 확인하세요.

## 현재 정식 2.0.6

업데이트 내용을 한글로 안내하며, 업데이트가 없으면 **“최신 버전을 사용하고 있습니다.”**를 표시합니다. 연결·승인 오류는 최신 버전 안내와 구분합니다. 파일 버전은 **2.0.147.0**입니다. 정확한 MSI의 두 OS 실제 업데이트와 GitHub/운영 서버 인증 전체 다운로드를 검증했습니다. 기존 정식 소스의 UI 수정만 포함하며 별도 개발 중인 자산조사·진단 베타와 관리자 설치본은 이번 직원용 릴리스에 포함하지 않습니다.

## 설치와 업데이트

정식 1.x는 릴리스의 ZIP을 해제한 뒤 `Setup.exe`로 설치합니다. 포터블 실행은 지원하지 않습니다. 정식 2.x는 직원용 MSI와 해당 릴리스 안내를 따르세요. 관리자/서버 설치본은 직원 클라이언트 MSI에 포함되지 않습니다.

V2.0.6은 정식 업데이트로 제공됩니다. 1.7.12의 업데이트 확인에서 2.x 직원용 MSI를 받을 수 있으며, 기존 2.x는 회사 업데이트 경로를 이용합니다. 일부 기존 화면·바로가기의 알파테스트/오픈베타 명칭과 채널 키는 호환성을 위해 남아 있습니다. 이 표시는 현재 GitHub 릴리스의 정식 상태와 별개이며, 화면 정리는 후속 설치본에서 적용합니다. 설치 전 업무 파일을 저장하고 공유폴더 문서·탐색기를 닫으세요.

이전 정식 2.0.5 수정 r4는 제품 표시 버전 **2.0.5**와 MSI 버전 **2.0.145**를 유지하고 내부 파일 버전만 **2.0.145.1**로 올렸습니다. 기존 2.0 정식 사용자는 앱의 **업데이트 → 다시 확인**에서 새 업데이트를 확인합니다. 설치 완료 세션 판정과 동일 MSI 버전의 실제 파일 교체도 수정했습니다. 기존 채널 선택·인증·부서별 접근 권한은 유지합니다.

- [정식 1.x 사용 안내](docs/USER-GUIDE-1.x.md)
- [GitHub Releases](https://github.com/droidbin/SMB-Manager-for-KCAA/releases)

V2.0.6 핵심 QA는 Windows 10/11 합계 **54/54개(100%)** 통과했습니다. 변경 영향이 없는 설치 UI·기존 전환·권한·복구 검사는 원래 해시와 적용 근거를 연결해 재사용했습니다. 유지보수 설치 취소 후 수동 재실행이 필요한 제한은 릴리스 안내에 기록했습니다.

| 경로 | 내용 |
|---|---|
| [V2.0.6 직원 클라이언트 소스](https://github.com/droidbin/SMB-Manager-for-KCAA/tree/V2.0.6/next/client-2.0) | 검증된 빌드의 직접 C# 소스 40개와 해시 목록; 런타임·서명 도구는 별도이며 MSI 바이트 재현 보장은 아님 |

| `tools/` | 소스 구성 검사와 기존 자산을 교체하지 않는 게시 도구 |
| `.local/legacy-builds/` | 로컬 빌드 출력, Git 제외 |

Windows에서 정식 소스를 빌드합니다.

```powershell
powershell -ExecutionPolicy Bypass -File ".\src\legacy\SMB Manager V1.7.11\source\build.ps1"
```

Actions는 빌드 산출물을 보관하며 일반 push에서는 릴리스를 게시하지 않습니다. 실제 게시에는 사전 검증한 패키지의 SHA256이 필요합니다. 빌드 성공은 실사용 QA 승인을 뜻하지 않습니다. 기존 정식 릴리스·태그·설치파일은 보존합니다.

이 저장소에 프로젝트 오픈소스 라이선스를 새로 부여하지 않았습니다. 제3자 자산의 안내는 해당 디렉터리에 있습니다.
