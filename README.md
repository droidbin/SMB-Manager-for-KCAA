# SMB Manager

Windows SMB 공유폴더를 부서별 드라이브로 연결하고, 연결 상태 점검과 자동 복구를 지원하는 **사내 업무용 프로그램**입니다. 개인·외부 기관·기업 대상 업데이트는 제공하지 않습니다.

## 다운로드

| 구분 | 버전 | 다운로드 |
|---|---|---|
| **정식** | **2.0.10** (파일 버전 2.0.157.0) | [V2.0.10 릴리스](https://github.com/droidbin/SMB-Manager-for-KCAA/releases/tag/V2.0.10) · [Latest](https://github.com/droidbin/SMB-Manager-for-KCAA/releases/latest) |
| 1.7 사용자 전환용 | V1.7.14 (안에 든 설치본은 2.0.10) | [V1.7.14 릴리스](https://github.com/droidbin/SMB-Manager-for-KCAA/releases/tag/V1.7.14) |

현재 정식보다 낮은 버전은 GitHub에서 받을 수 없습니다. 어떤 버전을 쓰고 있든 업데이트하면 바로 최신 정식으로 올라갑니다.

| 지금 쓰는 버전 | 업데이트 방법 |
|---|---|
| 2.0 정식 | 앱의 **업데이트 → 다시 확인**. 회사 관리 서버가 최신 정식(2.0.10)을 안내합니다 |
| 2.0 베타 | 같은 방법으로 2.0.10을 안내합니다(베타 채널도 현재 정식과 같음) |
| 1.7.7 · 1.7.8 | 앱의 업데이트 확인. 정식 릴리스의 직접 업데이트 zip으로 2.0.10을 설치합니다 |
| 1.7.9 ~ 1.7.12 | 앱의 업데이트 확인. 전환 릴리스 V1.7.14로 2.0.10을 설치합니다 |

1.7에서 업데이트하면 회사 서명된 `Setup.exe`가 함께 든 설치 파일의 해시와 서명을 확인한 뒤 설치합니다. 설치가 끝나면 2.0 앱이 1.7 실행 파일과 바로가기를 정리합니다. 설치를 취소하거나 실패하면 1.7 앱을 계속 사용할 수 있습니다.

설치 전에 업무 파일을 저장하고, 공유폴더 문서와 탐색기 창을 닫아 주세요. 관리자/서버 프로그램은 직원용 설치본에 포함되지 않습니다.

## 2.0.10 주요 내용

- **실명 등록:** 등록 성명은 실명 한글 2~4글자만 받습니다(공백·직함·영문·숫자 불가).
  - 이미 등록된 성명이 규칙에 맞지 않으면 앱 실행 시 '실명 등록 필요' 창이 뜹니다.
  - 보낸 실명은 담당자 승인 후 반영됩니다. 그동안 공유폴더 연결은 그대로 유지됩니다.
- **1.7 사용자:** 업데이트 확인 한 번으로 2.0.10을 바로 설치합니다.
- **관리 서버 무중단·상태 점검:** 관리 서버가 비정상 종료되면 자동으로 다시 시작합니다.
  - '서버' 화면에서 다음 항목을 경고와 함께 보여줍니다.
    - 디스크 여유
    - 저장 오류
    - HTTPS 인증서 만료
    - 마지막 백업
    - 자동 재시작 기록
- **자동 백업·복원:** 서버 데이터를 매일 백업합니다(기본 14개 보관).
  - '지금 백업', 암호 걸린 '이동용 백업', '복원'을 지원합니다.
  - 복원 전 데이터는 지우지 않고 옆 폴더로 옮겨 둡니다.
- **관리 화면 개편:** 왼쪽 메뉴와 홈 화면으로 정리했습니다.
  - PC 목록에 앱 버전·마지막 접속을 표시합니다.
  - 변경 이력을 검색하고 CSV로 저장할 수 있습니다.
- **끊김 알림:** 배정 폴더가 1분 넘게 끊겨 있으면 알림을 띄웁니다. 누르면 연결 진단이 열립니다.

## 2.0.8 주요 내용

- **관리자 업데이트 적용:** 관리자가 관리 프로그램에서 PC를 골라 최신 버전 설치를 요청할 수 있습니다.
  - 직원 화면에 10분 안내가 뜨고, 시간이 되면 앱이 종료된 뒤 자동으로 설치되고 다시 실행됩니다.
  - 설치는 함께 설치되는 'SMB Manager 업데이트 서비스'가 맡습니다. 이 서비스는 회사 서명된 직원 앱 설치 파일만, 현재보다 높은 버전으로만 설치합니다.
- **부서 변경 후 연결 안 되던 문제 수정:** 같은 회사 서버에 이전 부서 계정 연결이 남아 있으면 Windows가 새 계정 연결을 거부했습니다(오류 1219). 이제 앱이 남은 연결과 저장된 자격 증명을 자동으로 정리합니다. 열린 파일 때문에 정리하지 못하면, 파일이 닫히는 대로 자동으로 연결합니다.
- **업데이트 채널 정리:** 정식·베타 두 가지만 운영합니다. 이전 버전 앱의 예전 채널 요청도 베타로 안내합니다.

전체 변경 이력은 [업데이트 내역](docs/CHANGELOG.md)을 확인하세요.

## 테스트와 배포 기준

- **베타:** 내부 Windows 10/11 VM과 부서원 대상 시험.
- **정식:** 핵심 QA 필수 세부 항목의 통과율이 90% 이상이어야 합니다. 또한 중대 결함이 없고, 설치본 서명·무결성과 복구 준비, GitHub 및 회사 서버를 통한 실제 업데이트 전달을 확인해야 전체 임직원 대상으로 전환합니다.
- 핵심 QA 항목:
  - 실제 설치·업데이트와 등록·설정 보존
  - 별도 서버에 실제 연결해 권한과 파일 작업 확인
  - 변경 영향과 중대 문제 검토
  - 서명·무결성·복구 준비
  - GitHub 및 인증된 앱 전달
- 미실행·실패 항목은 통과로 세지 않습니다.

2.0.10 정식 전환 시 핵심 QA는 **78/78(100%), 실패 0**이었습니다(관리자 PC 실제 설치 포함). 자세한 기준은 [배포 기준과 이력](docs/DISTRIBUTION.md)에 있습니다.
