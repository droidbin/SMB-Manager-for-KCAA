# 업데이트 내역

현재 정식은 **2.0.8**입니다. 이전 버전은 GitHub에서 받을 수 없으며, 어떤 버전에서든 업데이트하면 최신 정식으로 바로 올라갑니다.

## 2.0.8 — 2026-11-07 (정식)

- **관리자 업데이트 적용:** 관리자가 관리 프로그램의 '강제 업데이트'에서 PC를 골라 최신 버전 설치를 요청할 수 있습니다.
  - 직원 화면에 10분 안내가 뜨며 미룰 수 없습니다. '지금 설치'로 바로 설치할 수도 있습니다.
  - 시간이 되면 앱이 종료되고 자동으로 설치된 뒤 다시 실행됩니다.
  - 관리 화면에서 PC별 버전, 지원 여부, 진행 상태(받는 중·안내 중·설치 중·완료·실패)를 확인할 수 있습니다.
- **SMB Manager 업데이트 서비스 추가:** 관리자 업데이트를 설치하는 Windows 서비스입니다. 회사 서명된 직원 앱 설치 파일만 설치합니다. 현재보다 높은 버전으로만 설치하며, 서명 검증을 통과하지 못한 파일은 거부합니다.
- **부서 변경 후 공유폴더가 연결되지 않던 문제 수정(Windows 오류 1219):** 같은 회사 서버에 남은 이전 계정 연결을 앱이 자동으로 정리합니다. 대상은 다음과 같습니다.
  - 연결 중인 드라이브와 1.7에서 기억된 드라이브
  - 드라이브 없이 연결된 경로
  - 저장된 자격 증명
  - 열린 파일 때문에 정리하지 못하면 관리 화면에 원인을 표시하고, 파일이 닫히는 대로 자동으로 연결합니다.
- **업데이트 채널:** 정식·베타 두 가지만 운영합니다. 2.0.5 이전 앱이 예전 채널로 요청해도 베타 업데이트를 안내합니다.
- **1.7 사용자 전환:** 1.7.7 이후 모든 1.7 버전이 업데이트 확인 한 번으로 2.0.8을 설치합니다.
- 관리 프로그램 화면과 관리 서버 안정성을 개선했습니다.

## 2.0.6 (정식)

- 업데이트 내용을 한글로 안내합니다.
- 업데이트가 없으면 "최신 버전을 사용하고 있습니다."를 표시합니다. 연결·승인 오류는 최신 버전 안내와 구분합니다.

## 2.0.5 수정 r4 (정식)

- 기존 2.0.5 사용자가 수정본을 새 업데이트로 인식하도록 내부 파일 버전을 2.0.145.1로 올렸습니다.
- 설치 완료 판정과 같은 버전 파일 교체 문제를 수정했습니다.

## 2.0.5 (정식)

- 업데이트 채널을 정식·베타로 정리했습니다.
- 업무 포털 바로가기를 추가했습니다.

## V1.7.13 — 2026-11-07 (전환 릴리스)

- 1.7.9~1.7.12 사용자를 2.0.8로 바로 옮기는 전환용 릴리스입니다. 새 1.7 버전이 아니며, 안에 든 설치 파일은 2.0.8입니다.

## 1.7.12

- 1.7에서 2.0으로 전환하는 업데이트 안내를 추가했습니다. 업데이트 채널(정식·베타) 선택을 명확하게 표시합니다.

## 1.7.11

- 연결 해제 후 자동 재연결이 호출되지 않던 문제를 수정했습니다.
- 다른 공유가 드라이브 문자를 쓰고 있으면 보존하고 충돌을 표시합니다. 충돌이 해소되면 자동으로 다시 연결합니다.
- 점검과 복구를 백그라운드에서 실행합니다. 기본 점검 주기는 60초입니다.

## 1.7.10

- 앱·설치·제거 프로그램과 제목줄·트레이에 공유폴더 아이콘을 적용했습니다.
- 앱을 시작할 때 새 버전이 있으면 팝업으로 안내합니다.

## 1.7.9

- 업데이트 채널(정식 버전만 / 베타 버전 포함)을 선택할 수 있습니다.

## 1.7.8

- 설치 표식이 없는 압축 해제본은 바로 실행하지 않고 설치 프로그램으로 전환합니다.
