# 업데이트 내역

현재 정식은 **2.0.8**, 베타는 **2.0.10-beta.1**입니다. 이전 버전은 GitHub에서 받을 수 없으며, 어떤 버전에서든 업데이트하면 최신 정식으로 바로 올라갑니다.

## 2.0.10-beta.1 — 2026-11-08 (베타)

- **관리 서버 무중단:** 관리 서버가 비정상 종료되면 5초·15초·60초 간격으로 자동으로 다시 시작합니다. 10분 안에 5번 실패하면 멈추고 관리 화면에 알립니다.
  - 관리 화면만 비정상 종료되면 서버는 그대로 두고 화면만 다시 엽니다.
  - 설치 프로그램이 실행 중일 때는 다시 시작하지 않습니다.
- **서버 상태 점검:** 디스크 여유(5GB 또는 10% 미만), 저장 오류, HTTPS 인증서 만료(30일 이내), 마지막 백업(36시간 초과), 최근 24시간 자동 재시작을 경고로 보여줍니다.
  - 서버 오류·시작·종료를 관리자 PC에 날짜별로 7일 동안 기록합니다. 키·암호는 가려서 씁니다.
- **자동 백업·복원:** 매일 정한 시각(기본 12:30)에 서버 데이터를 백업하고 정한 개수(기본 14개)만 보관합니다. 백업 직후 다시 읽어 검증합니다.
  - 백업은 관리자 PC의 Windows 계정으로 암호화됩니다. 다른 PC로 옮길 때는 별도 암호의 '이동용 백업'을 만듭니다(암호는 저장하지 않음).
  - 복원하면 관리 화면이 잠시 닫혔다가 다시 열립니다. 복원 전 데이터는 지우지 않고 옆 폴더로 옮기며, 복원한 데이터로 서버가 시작되지 않으면 원래 데이터로 되돌립니다.
- **관리 화면 개편:** 툴바 버튼을 왼쪽 메뉴로 정리하고, 홈 화면에 접속 PC·승인 대기·정정 요청·구버전·서버 상태·마지막 백업을 모았습니다.
  - PC 목록에 앱 버전·마지막 접속을 표시합니다.
  - 관리 변경 이력을 5,000건까지 보관하고 기간·작업·검색어로 걸러 CSV로 저장할 수 있습니다.
- **직원 앱 끊김 알림:** 배정 폴더가 1분 넘게 끊긴 채 자동 복구되지 않으면 알림을 띄웁니다. 누르면 연결 진단이 열립니다.
  - 같은 폴더는 30분에 한 번만 알립니다. 관리자가 연결을 보류했거나 보호 잠금·사용자 일시중지 중일 때는 알리지 않습니다.

## 2.0.9-beta.1 — 2026-11-07 (베타)

- **버전 현황 · 강제 업데이트:** 관리 프로그램의 '버전 현황 · 강제 업데이트'에서 모든 PC의 앱 버전과 채널 배포 버전, 최신/구버전 여부를 한 화면에 봅니다.
  - 부서·구버전·진행 중·실패·꺼진 PC로 걸러 볼 수 있습니다.
  - 구버전 PC나 실패·응답 없는 PC를 한 번에 골라 요청할 수 있습니다.
- **예약:** 정한 시각까지 회사 서버가 요청을 보류합니다. 시각이 지나면 PC가 받아 10분 안내 후 설치합니다. 이미 설치된 2.0.8 앱에도 적용됩니다.
- **실패 알림:** 실패하거나 단계가 평소보다 오래 멈춘 요청은 '응답 없음'으로 표시되고, 관리 프로그램 메인 화면에 대수가 나옵니다. 같은 PC를 다시 선택하면 재요청합니다.
- **연결 진단(직원 앱):** '연결 진단' 버튼과 트레이 메뉴에서 엽니다.
  - 회사 서버 → 등록 승인 → 폴더 배정 → 파일 서버 → 드라이브 순서로 확인하고, 막힌 곳을 쉬운 말로 알려줍니다.
  - 끊긴 폴더는 '다시 연결'로 바로 붙일 수 있습니다.
  - 담당자에게 보낼 내용을 복사할 수 있습니다. 계정·암호는 넣지 않습니다.
- **정확한 버전 표시:** 직원 앱이 회사 서버에 자기 버전을 알려 관리 화면에 정확한 버전이 나옵니다.

## 2.0.8 — 2026-11-07 (정식)

- **관리자 업데이트 적용:** 관리자가 관리 프로그램의 '강제 업데이트'에서 PC를 골라 최신 버전 설치를 요청할 수 있습니다.
  - 직원 화면에 10분 안내가 뜨며 미룰 수 없습니다. '지금 설치'로 바로 설치할 수도 있습니다.
  - 시간이 되면 앱이 종료되고 자동으로 설치된 뒤 다시 실행됩니다.
  - 관리 화면에서 PC별 버전, 지원 여부, 진행 상태(받는 중·안내 중·설치 중·완료·실패)를 확인할 수 있습니다.
- **SMB Manager 업데이트 서비스 추가:** 관리자 업데이트를 설치하는 Windows 서비스입니다. 회사 서명된 직원 앱 설치 파일만 설치합니다. 현재보다 높은 버전으로만 설치하며, 서명 검증을 통과하지 못한 파일은 거부합니다.
- **부서 변경 후 공유폴더가 연결되지 않던 문제 수정(Windows 오류 1219):** 같은 회사 서버에 남은 이전 계정 연결을 앱이 자동으로 정리합니다. 대상은 다음과 같습니다.
  - 연결 중인 드라이브와 1.7에서 기억된 드라이브
  - 드라이브 없이 연결된 경로
  - 저장된 자격 증명
  - 열린 파일 때문에 정리하지 못하면 관리 화면에 원인을 표시하고, 파일이 닫히는 대로 자동으로 연결합니다.
- **업데이트 채널:** 정식·베타 두 가지만 운영합니다. 2.0.5 이전 앱이 예전 채널로 요청해도 베타 업데이트를 안내합니다.
- **1.7 사용자 전환:** 1.7.7 이후 모든 1.7 버전이 업데이트 확인 한 번으로 2.0.8을 설치합니다.
- 관리 프로그램 화면과 관리 서버 안정성을 개선했습니다.

## 2.0.6 (정식)

- 업데이트 내용을 한글로 안내합니다.
- 업데이트가 없으면 "최신 버전을 사용하고 있습니다."를 표시합니다. 연결·승인 오류는 최신 버전 안내와 구분합니다.

## 2.0.5 수정 r4 (정식)

- 기존 2.0.5 사용자가 수정본을 새 업데이트로 인식하도록 내부 파일 버전을 2.0.145.1로 올렸습니다.
- 설치 완료 판정과 같은 버전 파일 교체 문제를 수정했습니다.

## 2.0.5 (정식)

- 업데이트 채널을 정식·베타로 정리했습니다.
- 업무 포털 바로가기를 추가했습니다.

## V1.7.13 — 2026-11-07 (전환 릴리스)

- 1.7.9~1.7.12 사용자를 2.0.8로 바로 옮기는 전환용 릴리스입니다. 새 1.7 버전이 아니며, 안에 든 설치 파일은 2.0.8입니다.

## 1.7.12

- 1.7에서 2.0으로 전환하는 업데이트 안내를 추가했습니다. 업데이트 채널(정식·베타) 선택을 명확하게 표시합니다.

## 1.7.11

- 연결 해제 후 자동 재연결이 호출되지 않던 문제를 수정했습니다.
- 다른 공유가 드라이브 문자를 쓰고 있으면 보존하고 충돌을 표시합니다. 충돌이 해소되면 자동으로 다시 연결합니다.
- 점검과 복구를 백그라운드에서 실행합니다. 기본 점검 주기는 60초입니다.

- 앱을 시작할 때 새 버전이 있으면 팝업으로 안내합니다.

## 1.7.9

- 업데이트 채널(정식 버전만 / 베타 버전 포함)을 선택할 수 있습니다.
