# 업데이트 내역

현재 정식은 **2.0.11**입니다(베타 채널은 2.0.13-beta.1). 이전 버전은 GitHub에서 받을 수 없으며, 어떤 버전에서든 업데이트하면 최신 정식으로 바로 올라갑니다.

## 2.0.13-beta.1 — 2026-11-23 (베타, 직원 앱)

베타 채널을 고른 PC에만 안내됩니다. 현재 정식과 GitHub Latest는 **2.0.11** 그대로입니다. 2.0.12-beta.1의 변경을 모두 포함합니다.

- **공지 팝업:** 받은 회사 공지를 앱이 최소화되어 있거나 트레이에 있어도 팝업으로 보여줍니다. 업그레이드 직후에는 읽지 않은 공지 중 가장 최근 1건만 띄우고, 트레이 메뉴에서 최근 공지를 다시 볼 수 있습니다.
- **하단 공지창 제거:** 메인 창 아래의 검은색 이전 공지 목록 패널을 없앴습니다.
- **업무지원포털 앱(PWA) 자동 설치:** 설치·업데이트 시 기존 업무지원포털 바탕화면·시작 메뉴 바로가기를 정리하고 Edge와 Chrome에 업무지원포털 앱을 정책으로 설치합니다(브라우저에 "조직에서 관리" 표시가 나타날 수 있음). 기존 브라우저 정책 값은 보존·백업합니다.
- 파일 버전 2.0.160.0. 프로토콜·채널·권한은 바뀌지 않았습니다.
- **확인한 범위:** 시험PC의 Windows 10/11 VM에서 설치·업그레이드, 공지 팝업(창 표시·트레이 숨김), 하단 패널 제거, 바로가기 정리, Edge 정책 설치를 확인했습니다. 화면 잠금 중 공지, 125%·150% 배율과 다중 모니터, 트레이 메뉴, 업그레이드 직후 최신 1건만 팝업, 도메인 미가입 PC의 Chrome 정책, PWA 삭제 불가 여부, 이 빌드의 별도 서버 SMB 회귀 시험은 아직 확인하지 못했습니다. 릴리스 전체 QA 원장과 정식 전환 판정은 하지 않았습니다.

## 2.0.12-beta.1 — 2026-11-23 (베타, 직원 앱)

베타 채널을 고른 PC에만 안내됩니다. 현재 정식과 GitHub Latest는 **2.0.11** 그대로입니다.

- **이전 연결·저장 계정 완전 삭제:** 설치·업데이트 후 첫 실행, 그리고 서버 암호가 바뀔 때 이 앱이 관리하는 서버의 예전 영구 매핑과 Windows에 저장된 계정(도메인/일반 자격 증명)을 먼저 지웁니다. 낡은 정보로 반복 인증이 시도되어 서버 계정이 잠기던 원인을 없애기 위한 변경입니다. 다른 서버와 원격 데스크톱(TERMSRV) 자격 증명, 앱 설정은 보존하고 열린 파일은 강제로 닫지 않습니다.
- **인증 실패 중단:** 암호 오류·계정 잠김(Windows 오류 86/1326/1909)이 나면 새 계정 정보가 올 때까지 자동 재연결을 멈춥니다(잠김 15분, 그 외 2분).
- 파일 버전 2.0.159.0. 프로토콜·채널·권한은 바뀌지 않았습니다.
- **확인한 범위:** 시험PC의 Windows 10/11 VM에서 실제 업데이트, 재부팅·로그온, 별도 SMB 서버 연결과 서버 측 인증 실패 0건을 확인했습니다. 릴리스 전체 QA 원장과 정식 전환 판정은 아직 하지 않았습니다.

## 2.0.11 — 2026-11-17 (정식)

- **계정 잠김(Windows 오류 1909) 방지:** 인증 실패 후 같은 서버에 대한 재시도를 잠시 보류합니다(암호 오류 2분, 계정 잠김 15분). 새 암호 배정이나 관리자 복구 지시는 바로 처리합니다.
- **서버 암호 변경 후 연결 복구:** 서버 암호가 바뀌면 같은 서버의 앱 연결을 함께 정리하고 새 암호로 다시 맺습니다(이전에는 오류 1219로 일부 드라이브가 복구되지 않았음). 열린 파일은 강제로 닫지 않습니다.
- 설치 도우미가 관리자용 화면(AdminShell)도 인식하도록 보강했고, 계정 잠김 상태를 화면에서 구분해 보여줍니다.
- 파일 버전 2.0.158.0. 프로토콜·채널·권한은 바뀌지 않았습니다. 1.7.7·1.7.8은 정식 릴리스의 직접 업데이트 zip으로 2.0.11을 설치하고, 1.7.9~1.7.12는 전환 릴리스 V1.7.14로 2.0.10을 설치한 뒤 업데이트 확인으로 2.0.11에 올라갑니다.

## 관리자 2.1.2 — 2026-11-17 (정식, 관리자 전용)

관리자 앱만 바뀐 릴리스입니다. 직원용 앱은 2.0.11이며 GitHub의 Latest는 V2.0.11입니다.

- **잠긴 계정 복구 보호:** 직원 PC가 서버 계정 잠김을 보고하면 "배정 폴더 복구"를 보내지 않고 이유를 알려주며, 서버에서 잠금을 푼 뒤 "해제 확인 후 복구"로 보낼 수 있습니다.
- **서버 계정 제어 추가(선택 기능, 기본 꺼짐):** SMB 서버(Windows) 로컬 계정의 잠금 조회·해제와 서버 암호·저장 암호 동시 변경. Windows 원격 관리(WinRM)가 필요하고, 관리자 계정·암호는 이 PC에 암호화 저장되어 직원 PC에 전달되지 않습니다.
- **알려진 한계:** 서버 계정 제어는 실제 Windows 서버에서 시험하지 못했습니다. 2.1.0부터 이어진 Cloudflare 실제 터널·모바일 접속, 직원 PC 강제 업데이트 실설치, 설치 마침 버튼 경로도 확인하지 못했습니다.
- 파일 버전 2.1.162.0, 관리자 PC(Windows 11) 전용 암호 ZIP입니다. 서버 데이터와 직원 등록은 보존됩니다.

- **업무지원포털 푸시 알림 추가(기본 꺼짐):** PC 등록 승인 요청, 등록 정보 정정 요청, 오류·문의 신고, 보호 연결 차단 보고가 오면 포털의 통합 관리자 기기(PWA·브라우저, Android 앱 1.11.0 이상)로 알림을 보냅니다.

- 복구용 관리 화면의 글꼴 참조를 공유 글꼴 폴더로 정리했습니다.
- **알려진 한계:** Cloudflare 실제 터널·모바일 접속, 직원 PC 강제 업데이트 실설치, 설치 마침 버튼 경로는 확인하지 못했습니다. 조용한 설치(`/qn`) 후에는 서버가 자동으로 시작되지 않습니다.
- 파일 버전 2.1.161.0, 관리자 PC(Windows 11) 전용 암호 ZIP입니다. 서버 데이터와 직원 등록은 보존됩니다.

## 2.0.10-beta.1 — 2026-11-08 (베타)

- **관리 서버 무중단:** 관리 서버가 비정상 종료되면 5초·15초·60초 간격으로 자동으로 다시 시작합니다. 10분 안에 5번 실패하면 멈추고 관리 화면에 알립니다.
  - 관리 화면만 비정상 종료되면 서버는 그대로 두고 화면만 다시 엽니다.
  - 설치 프로그램이 실행 중일 때는 다시 시작하지 않습니다.
- **서버 상태 점검:** 디스크 여유(5GB 또는 10% 미만), 저장 오류, HTTPS 인증서 만료(30일 이내), 마지막 백업(36시간 초과), 최근 24시간 자동 재시작을 경고로 보여줍니다.
  - 서버 오류·시작·종료를 관리자 PC에 날짜별로 7일 동안 기록합니다. 키·암호는 가려서 씁니다.
- **자동 백업·복원:** 매일 정한 시각(기본 12:30)에 서버 데이터를 백업하고 정한 개수(기본 14개)만 보관합니다. 백업 직후 다시 읽어 검증합니다.
  - 백업은 관리자 PC의 Windows 계정으로 암호화됩니다. 다른 PC로 옮길 때는 별도 암호의 '이동용 백업'을 만듭니다(암호는 저장하지 않음).
  - 복원하면 관리 화면이 잠시 닫혔다가 다시 열립니다. 복원 전 데이터는 지우지 않고 옆 폴더로 옮기며, 복원한 데이터로 서버가 시작되지 않으면 원래 데이터로 되돌립니다.
- **관리 화면 개편:** 툴바 버튼을 왼쪽 메뉴로 정리하고, 홈 화면에 접속 PC·승인 대기·정정 요청·구버전·서버 상태·마지막 백업을 모았습니다.
  - PC 목록에 앱 버전·마지막 접속을 표시합니다.
  - 관리 변경 이력을 5,000건까지 보관하고 기간·작업·검색어로 걸러 CSV로 저장할 수 있습니다.
- **직원 앱 끊김 알림:** 배정 폴더가 1분 넘게 끊긴 채 자동 복구되지 않으면 알림을 띄웁니다. 누르면 연결 진단이 열립니다.
  - 같은 폴더는 30분에 한 번만 알립니다. 관리자가 연결을 보류했거나 보호 잠금·사용자 일시중지 중일 때는 알리지 않습니다.

  - 관리 화면에서 PC별 버전, 지원 여부, 진행 상태(받는 중·안내 중·설치 중·완료·실패)를 확인할 수 있습니다.
- **SMB Manager 업데이트 서비스 추가:** 관리자 업데이트를 설치하는 Windows 서비스입니다. 회사 서명된 직원 앱 설치 파일만 설치합니다. 현재보다 높은 버전으로만 설치하며, 서명 검증을 통과하지 못한 파일은 거부합니다.
- **부서 변경 후 공유폴더가 연결되지 않던 문제 수정(Windows 오류 1219):** 같은 회사 서버에 남은 이전 계정 연결을 앱이 자동으로 정리합니다. 대상은 다음과 같습니다.
  - 연결 중인 드라이브와 1.7에서 기억된 드라이브
  - 드라이브 없이 연결된 경로
  - 저장된 자격 증명
  - 열린 파일 때문에 정리하지 못하면 관리 화면에 원인을 표시하고, 파일이 닫히는 대로 자동으로 연결합니다.
- **업데이트 채널:** 정식·베타 두 가지만 운영합니다. 2.0.5 이전 앱이 예전 채널로 요청해도 베타 업데이트를 안내합니다.
- **1.7 사용자 전환:** 1.7.7 이후 모든 1.7 버전이 업데이트 확인 한 번으로 2.0.8을 설치합니다.
- 관리 프로그램 화면과 관리 서버 안정성을 개선했습니다.
