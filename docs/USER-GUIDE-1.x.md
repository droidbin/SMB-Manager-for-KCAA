# SMB Manager

Windows SMB 공유폴더를 부서별 Drive로 연결하고, 연결 상태 점검과 자동 재연결을 지원하는 사내 업무용 프로그램입니다.

※ 사내 업무용 프로그램으로, 개인 및 외부 기관, 기업을 대상으로 업데이트를 제공하지 않습니다.

**현재 정식 버전: V1.7.11**

## 다운로드 및 설치

- [V1.7.11 정식 릴리즈](https://github.com/droidbin/SMB-Manager-for-KCAA/releases/tag/V1.7.11)
- [V1.7.11 설치 패키지 다운로드](https://github.com/droidbin/SMB-Manager-for-KCAA/releases/download/V1.7.11/SMB.Manager.V1.7.11.zip)
- [최신 정식 릴리즈](https://github.com/droidbin/SMB-Manager-for-KCAA/releases/latest)

1. 릴리즈의 `SMB.Manager.V1.7.11.zip`을 다운로드하고 압축을 해제합니다.
2. 압축 해제한 폴더에서 `Setup.exe`를 실행합니다.
3. 설치를 완료한 뒤 생성된 바로가기로 프로그램을 실행합니다.

**포터블 실행은 지원하지 않습니다.** 압축 해제한 앱을 직접 실행하면 설치 프로그램으로 전환합니다. ZIP은 설치 파일을 담은 배포 패키지입니다.

## V1.7.11 변경 사항

연결 해제 후 반복 자동 재연결이 동작하지 않던 문제를 수정한 정식 핫픽스입니다.

- **상태·자동 재연결**이 켜져 있으면 마지막 연결 부서의 공유폴더를 주기적으로 점검하고 끊긴 연결을 복구합니다.
- 재연결에 실패해도 다음 점검 주기에 다시 시도합니다. 기본 점검 주기는 **60초**입니다.
- 자동 복구 과정에서 정상 매핑, 다른 공유의 드라이브 매핑, 저장된 자격 증명을 삭제하지 않습니다.
- 다른 공유가 같은 드라이브 문자를 사용 중이면 기존 연결을 보존하고 충돌을 표시합니다. 충돌이 해소되면 다시 연결을 시도합니다.
- 점검·복구를 백그라운드에서 수행하고 중복 작업을 방지합니다.

## 주요 기능

- 부서별 공유폴더 연결 및 전체 연결 해제
- SMB 연결 상태 점검, 진단 로그, 자동 복구
- 저장된 비밀번호를 이용한 주기적 자동 재연결
- 서버 주소, 공유폴더 이름, 드라이브 문자, Drive 계정 설정
- 일반 설정과 보안 설정, 앱 내부 관리자 비밀번호 관리
- GitHub Releases 기반 업데이트 확인 및 설치
- 정식 버전만 / 베타 버전 포함 업데이트 채널 선택
- 시작 시 새 버전 팝업 안내
- 트레이 백그라운드 실행 및 선택적 Windows 시작프로그램 등록
- `Uninstall.exe`를 통한 제거

## 자동 재연결 사용 방법

1. 부서를 선택하고 Drive 접속 비밀번호를 입력합니다.
2. **비밀번호 저장**을 선택하고 연결합니다.
3. **상태·자동 재연결**을 켭니다.

이후 마지막 연결 부서의 폴더를 점검하고 저장된 비밀번호로 복구합니다. 저장된 비밀번호가 없으면 비밀번호 입력이 필요합니다. 실제 재시도 시점은 네트워크 응답 시간과 진행 중인 작업에 따라 달라질 수 있습니다.

**전체 연결 해제 후에도 상태·자동 재연결이 켜져 있으면 다시 연결됩니다.** 연결을 끊어 둬야 한다면 먼저 해당 옵션을 끄세요.

설치 시 시작프로그램 등록을 선택하면 Windows 로그인 후 앱이 트레이에서 실행되고, 저장된 비밀번호로 업무폴더 재연결을 시도합니다.

## 창 닫기와 프로그램 종료

- 창의 **X 버튼 또는 최소화 버튼**을 누르면 트레이에서 계속 실행됩니다.
- 완전히 종료하려면 앱 상단의 **종료** 또는 트레이 메뉴의 **종료**를 사용하세요.

## 업데이트

### 1.7.10에서 1.7.11로 업데이트

앱을 완전히 종료한 뒤 다시 실행하면 시작 시 새 버전 알림을 확인할 수 있습니다.

- **자동 업데이트 켜짐:** 확인 전용 알림에서 확인하면 다운로드와 설치 프로그램으로 진행합니다.
- **자동 업데이트 꺼짐:** 알림에서 설치 여부를 선택합니다.
- 수동 설치는 위 V1.7.11 패키지를 받아 `Setup.exe`로 진행합니다.

이미 실행 중인 앱에 서버가 즉시 푸시하거나 무인으로 강제 설치하는 방식은 아닙니다. 설치 프로그램에서 설치를 완료해야 합니다. 더 오래된 버전은 해당 버전의 업데이트 동작에 따라 수동 설치가 필요할 수 있습니다.

### 업데이트 채널

**일반 설정 → 일반 → 업데이트 채널**에서 선택하고 저장합니다.

- **정식 버전만:** 기본값입니다.
- **베타 버전 포함:** 1.x 계열 안에서 현재보다 높은 정식·베타 릴리즈를 확인합니다. 2.x 알파테스트는 이 옵션의 대상이 아닙니다.

자동·수동 업데이트 모두 저장된 채널을 따르며, 채널을 변경해도 낮은 버전으로 자동 다운그레이드하지 않습니다.

업데이트 패키지는 현재보다 높은 버전의 릴리즈와 `Setup.exe`가 포함된 ZIP이 필요합니다.

### 공유폴더 방식 구버전의 설치 전환

공유폴더 업데이트를 사용하던 PC는 관리자가 `지점공용\App Update`에 배포용 `latest.ini`와 같은 버전의 EXE를 함께 배치해 설치 방식으로 전환할 수 있습니다.

V1.7.11 배포 파일은 `latest.ini`의 `Version=V1.7.11`, `FileName=SMB Manager V1.7.11.exe`와 일치해야 합니다. 구버전이 새 EXE를 실행하면 내장 설치 프로그램으로 전환하며, 사용자가 설치를 완료해야 합니다.

## 설정과 보안

- 앱 내부 관리자 비밀번호는 PBKDF2 해시로 저장합니다.
- Drive 계정명과 저장을 선택한 접속 비밀번호는 Windows DPAPI CurrentUser 방식으로 암호화합니다.
- 암호화된 설정은 해당 Windows 사용자 문맥에 종속되므로 다른 PC·사용자에게 그대로 복사하는 배포 방식을 사용하지 마세요.
- 앱 내부 관리자 비밀번호는 앱의 보안 설정용입니다. 실제 공유폴더 접근 권한은 공유 서버의 계정·권한 설정에 따릅니다.
- 제거 시 사용자 설정, 진단 로그, 저장된 비밀번호 삭제 여부를 선택할 수 있습니다.
- 관리자 비밀번호 초기화 도구는 일반 배포 ZIP에 포함하지 않습니다.

## V1.7.11 검증 범위

배포용 설치 프로그램으로 1.7.10 → 1.7.11 업그레이드와 실행을 확인했으며, 실제 SMB 공유 서버에서 **18개 항목**을 검증했습니다.

- 연결 해제 후 반복 복구
- 드라이브 문자 충돌 시 기존 매핑 보존 및 충돌 해소 후 복구
- 존재하지 않는 공유의 오류 발생 후 재시도
- 기존 업무 연결과 저장된 비밀번호 보존
- 시험용 매핑 정리 및 설정 복원

상세 결과는 설치 패키지의 `REAL-RECONNECT-QA.md`를 참고하세요. 네트워크 전체 단절, 서버 재부팅, 보안 프로그램별 호환성은 해당 시험에 포함되지 않았습니다.
