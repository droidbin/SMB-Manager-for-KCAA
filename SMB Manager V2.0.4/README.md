# SMB Manager V2.0.4

## V2.0.4 기능

- 앱 및 설치 프로그램에서 Windows 시작 프로그램 자동 등록과 로그인 후 자동 연결 기능 제거
- 앱 실행 시 기존 SMB Manager 시작 프로그램 바로가기 정리

## V2.0.3 기능

- 설치 전환 중 앱 실행 파일을 임시 폴더에 복제하지 않고 원본 경로를 설치 프로그램에 전달

- 일반 실행을 자동 시작으로 잘못 판단해 창이 숨겨지던 문제 수정
- 설치 프로그램 창과 옵션 영역 크기를 조정해 화면 잘림 완화

- 화면 개편: 연결 상태 요약과 업무별 영역을 갖춘 대시보드
- 자가보호: 설치 파일/설정 무결성 감지와 변경 기록, 복구 안내
- 방화벽 도우미: 서버 TCP 445 경로 상태 점검. 규칙을 자동 변경하지 않음
- 재부팅 복구 안전성: 사용자가 저장을 선택한 비밀번호만 사용하고 실패 시 기존 연결/자격 증명을 보존
- 연결 및 보안 설정 변경 이력 제공
- 프로그램 제거 시 매번 새로 생성되는 보안문자 숫자 4자리 확인

자가보호는 관리자나 안전 모드까지 차단하는 방식이 아니라 실행 파일의 SHA-256 변경 감지와 기록으로 한정합니다. 기준 해시 파일까지 함께 바뀌는 경우를 막는 서명 기반 보호는 제공하지 않습니다. 방화벽 도우미는 서버 TCP 445 접속 경로를 확인하며 규칙을 변경하지 않습니다.

## V2.0.3 구현 범위

- 메인 화면 상단에 SMB 연결 개수, 서버 TCP 445 경로, 설치 앱 무결성을 요약 표시
- 설치 패키지의 `integrity.sha256`과 현재 실행 파일 SHA-256을 비교해 무결성 변경을 기록
- 방화벽 점검은 서버 TCP 445 접속 가능 여부를 확인. 연결 실패만으로 방화벽 차단이라고 단정하지 않으며 인바운드 규칙은 추가하지 않음

부서를 선택하면 해당 부서에서 사용하는 Windows SMB 공유폴더를 자동으로 연결하는 관리 도구입니다.

## 실행 방법

`Setup.exe`를 실행해 설치합니다.

포터블 실행은 지원하지 않습니다. 앱 실행 파일을 직접 열면 설치 여부를 확인해 설치 프로그램을 실행합니다.

## 참고 사항

- 관리자 부서 연결은 별도의 앱 내부 관리자 인증 없이 SMB 계정으로 바로 연결합니다.
- 앱 내부 관리자 비밀번호는 설정 화면의 `보안` 탭에서 변경합니다.
- 앱 내부 관리자 비밀번호가 없으면 `보안 설정` 버튼을 처음 누를 때 한 번 설정합니다.
- SMB 계정명은 설정 파일에 DPAPI CurrentUser 방식으로 암호화 저장됩니다.
- 기존 Base64 계정명 설정은 실행 시 자동으로 암호화 저장 형식으로 마이그레이션됩니다.
- 연결 화면에서 `비밀번호 저장`을 선택한 경우에만 SMB 접속 비밀번호를 저장합니다.
- 저장된 SMB 비밀번호는 Windows DPAPI CurrentUser 방식으로 암호화되며 같은 Windows 사용자 계정에서만 복호화할 수 있습니다.
- 제거 시 사용자 설정, 진단 로그, 저장된 비밀번호 삭제 여부를 선택할 수 있습니다.
- 창의 X 버튼 또는 최소화 버튼을 누르면 앱은 종료되지 않고 트레이에서 계속 실행됩니다.
- 실제 종료는 앱 상단의 `종료` 버튼 또는 트레이 메뉴의 `종료`에서 수행합니다.
- 설치 시 시작프로그램 등록을 선택하면 Windows 부팅 후 앱이 트레이에서 실행되고 저장된 비밀번호로 업무폴더를 자동 재연결합니다.

## 공유폴더 구버전 브리지 업데이트

기존 공유폴더 업데이트를 사용하는 PC를 정식 설치 방식으로 전환하려면 `지점공용\App Update`에 아래 두 파일을 복사합니다.

- `latest.ini`
- `SMB Manager V1.7.7.exe`

구버전은 새 EXE를 기존 방식으로 복사해 실행합니다. 새 EXE는 내장된 `Setup.exe`와 `Uninstall.exe`를 임시 폴더에 꺼낸 뒤 설치 프로그램을 실행합니다. 사용자가 설치 버튼을 누르면 이후 업데이트는 GitHub ZIP 기반 정식 설치 방식으로 진행됩니다.

`latest.ini`의 배포 판정용 버전은 앱 자체 버전과 같은 `V1.7.7`입니다.
